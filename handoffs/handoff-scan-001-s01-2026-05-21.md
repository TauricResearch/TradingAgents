### Scan logic
- **Entry:** all 6 gates must pass for BUY. MA150 always enforced (not relaxable).
- **Exit triggers (any one → SELL):** RSI>70, price≥upper BB, MACD death cross
- **Relax flags:** each gate individually toggleable via `--relax=GATE`

## Known issues / decisions to preserve

- **MACD signal line computation** — loop recomputes both EMAs per bar for the MACD series (O(n²) but n≤200 bars, acceptable). If a faster approach is needed, memoize.
- **ADX requires ≥40 bars** for a meaningful reading (14-bar seed + 14-bar smoothing). `computeSnapshot` requires 150 bars anyway.
- **`isNaN` → `Number.isNaN`** — biome lint rule enforced across the codebase. New code must use `Number.isNaN()` not global `isNaN()`.
- **150-bar minimum** — both `computeSnapshot` (indicators.ts) and the scan CLI enforce this for MA150. Tickers with fewer bars return null/graceful error.
