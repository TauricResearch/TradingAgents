当前架构通过 **JSON 文件**提供持仓。你可以把文件放在项目根目录的 `portfolios` 文件夹中：

`/Users/yifeng/Desktop/软工/project/CS5351-new/portfolios/my_portfolio.json`

示例格式：

```json
{
  "cash": 25000.0,
  "currency": "USD",
  "positions": [
    {
      "ticker": "NVDA",
      "quantity": 120,
      "average_price": 150.0
    }
  ]
}
```

`positions` 是必填项；每项需要 `ticker` 和 `quantity`。`average_price`、`cash`、`currency` 可以省略或填 `null` 表示未知，别用 `0` 代替未知值。`positions: []` 表示你明确没有任何持仓；不提供持仓文件则表示系统不知道你的持仓，这两种情况不同。

### 运行方式

从项目根目录运行，并用 `--portfolio` 指定文件：

```bash
cd "/Users/yifeng/Desktop/软工/project/CS5351-new"
python -m cli.main --ticker NVDA --date 2026-11-15 --portfolio portfolios/my_portfolio.json
```

运行时会显示所选文件和分析日期，并询问是否继续发送持仓信息给模型；确认后才开始分析。也可以不加 `--portfolio`，运行 `python -m cli.main`，再从交互界面选择持仓文件。交互选择只扫描 `portfolios` 文件夹下**第一层**的 JSON 文件。

持仓快照日期会与分析日期关联。报告和 manifest 会记录输入模式、文件名和内容指纹。相关实现见[持仓输入服务](</Users/yifeng/Desktop/软工/project/CS5351-new/tradingagents/runapi/input_service.py>)和[CLI 参数](</Users/yifeng/Desktop/软工/project/CS5351-new/cli/main.py>)；README 中也有[当前持仓示例](</Users/yifeng/Desktop/软工/project/CS5351-new/README.md:314>)。
