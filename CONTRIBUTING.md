# Contributing

Thank you for helping with TradingAgents. Issues and pull requests are welcome.

## Reporting an issue

Give the output of `tradingagents --version`, the model you use, what you did, what you expected and what
happened. Remove keys and anything private first.

## Opening a pull request

- Keep one change to a pull request, and say what it does and why.
- Open an issue first for a large change or a new dependency.
- Make sure `npm run typecheck`, `npm run lint` and `npm run build` pass (Node.js 22 or later, after `npm ci`).
- Do not commit credentials or machine-specific paths and hosts.

## Security

Report a security problem privately, as [SECURITY.md](SECURITY.md) says, not in an issue.
