# Offline evidence — time filtering (INV-02)

Test spec for INV-02 evidence time filtering. `test_time_policy.py` holds 12
test functions driven by the `E-01` … `E-31` fixtures.

## Scope

- **Is**: the time-policy layer only — `is_admissible()` / `TimeVerdict` for a
  single evidence item, plus the fixture set as test data.
- **Is not**: `EvidenceItem` / `EvidencePack` construction, pack field
  completeness, `pack_hash`, and pack-level dedupe / conflict / citation /
  integrity outcomes. Those fixtures (E-02…E-06, E-08…E-12, E-21…E-26, E-29,
  E-30) are carried here as data and are asserted by a separate FR-01 pack
  test PR once contracts v1 is frozen. See `docs/req/trace-FR-01-evidence.md`.

## Running

The repo's pytest config sets `testpaths = ["tests"]`, so run this suite by
path:

```sh
pytest test/offline/evidence -m "not integration"
```

## Red / green

- **Red**: `src/egta/evidence/time_policy.py` does not exist, so
  `_target.py` records `MISSING_REASON` and re-raises the `ModuleNotFoundError`,
  which fails collection (`exit 2`). This is the expected starting state; the
  captured run is in `docs/evidence/FR-01/red-baseline.txt`.
- **Green**: once `egta.evidence.time_policy` provides `is_admissible` and
  `TimeVerdict`, the import succeeds and `TARGET_AVAILABLE` is `True`.

Fixtures are `test/offline/evidence/fixtures/E-01.json` … `E-31.json`,
generated by `scripts/gen_evidence_fixtures.py` (deterministic; re-running
reproduces byte-identical files). `E-21-2` is the duplicate copy of
`E-21-1` used by the dedupe case. `conftest.py` provides `frozen_now`,
`load_case(case_id)` and `iter_items(case)`.

## Boundary rule

`as_of` is a **closed** interval: an item whose `published_at` equals `as_of`
exactly is admitted, and a `date_only` value on the as-of UTC date is admitted
(fixture `E-31`, tests `test_date_only_equal_to_as_of_date_admitted` and
`test_published_at_exactly_equal_to_as_of_admitted`).
