Test the calls before you trust them

Backtests replay the whole team across a grid of tickers and dates, then score each call against the benchmark.

  1. Choose a grid

    Pick tickers, a date range and a spacing. Each cell is one ticker on one day.

    Example grid: two tickers across seven dates.

  2. Run every cell in full

    Each cell runs all five desks, exactly like a live analysis. Stop any time and resume later.

  3. Score the alpha

    Each call's return against the benchmark is measured over a holding window, then grouped by rating with a hit rate.
