# 看板可以改 LLM 配置，仍然不能动账户

在 ADR 0005「看板只读」之外开一个窄口：看板的「设置」页可以切换研判用的模型（深度 / 快速两档）和它们的单价，写进 `TRADER_HOME/settings.json`，日频和日内两个账户在下一次运行时读取，优先级高于 `.env`。账户状态（解除熔断、手动研判、调仓）仍然不开放。原因是模型和单价是运营配置，不是账户事实：改错了下一次运行就能改回来，不会产生不可逆的成交；而把它留在 `.env` 里，产品阶段的用户没法用。代价是切换会改变研判的指纹，两个账户的验证期都会从下一次运行起重新计时，所以切换前必须弹确认，并把每次变更追加到 `settings.json` 的历史里；验证期重算本身由账户任务在下一次运行时记录事件。

可选的模型来自上游的模型目录加上当前配置的模型，另外允许手填模型 ID（上游目录滞后于厂商发布，现在用的模型就不在里面）。只列出已配置 API 密钥的 provider。单价优先用仓库里整理的官方定价表（标注来源和日期），表里没有的模型要求手填，因为费用核算和月度预算都依赖它。

## Consequences

- 看板仍无认证，只绑本机回环；产品阶段开放给用户前，这个写入面必须先加登录和审计。
- `Settings.from_env` 和 `build_config` 多一层覆盖来源，`.env` 只剩下密钥和默认值的作用。
- 官方定价表要人工维护，表里要带 `as_of` 日期，过期的价格要能在界面上看出来。
