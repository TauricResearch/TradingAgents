# 研判日取运行时刻所在 UTC 日的前一天

每天 00:00 UTC 之后运行，`trade_date` 填前一个 UTC 日，进程固定在 UTC 时区。原因是 `tradingagents` 按"日期 ≤ trade_date"过滤行情，不区分当天的日线有没有收盘。填当天的话，会混进刚开盘、成交量接近 0 的 K 线，扭曲 ATR、volume 等指标。另外，项目判断"今天"和划分缓存日界都用本机日期，进程固定在 UTC 后，这两者才和加密货币的日线边界一致。

## Consequences

- 这次运行会被当作历史运行，Polymarket 和实时概况被屏蔽。这对加密货币影响不大。
- memory 结算的入场价比模拟盘的实际成交晚约 24 小时。这只影响 PM 读到的反思，不影响按账本计算的策略表现。

## Considered Options

- 改数据层，丢弃未收盘的 K 线：与 0001 冲突。
