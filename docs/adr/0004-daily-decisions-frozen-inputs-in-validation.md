# 验证期内按日决策，研判输入冻结，盘中只靠止损和熔断

目标是一个根据新闻、行情和宏观数据自动交易的程序。第一版把"根据市场变化"定为每天一次：每个 UTC 日收盘后研判一次、定一次方向，盘中只有止损和熔断按分钟对价格作出反应。验证期内研判的输入也冻结：不加数据源（资金费率、持仓量、链上数据，以及被 ADR 0002 屏蔽的 Polymarket 都不加），不换模型。原因是现在还不知道评级有没有预测力，在这之前加输入或加快频率，多花的钱和多出的改动都没法归因。另外，盘中跑 LLM 研判的成本随触发次数成倍上涨，而上游防前视偏差的机制全部按日期划界，到小时级就不成立。

## Consequences

- 一条新闻从发生到进入决策，最长要等近 24 小时。
- 评级有没有预测力，由结算的 alpha 和策略相对对照组合的表现回答，验证期结束后才选下一步（见 `docs/roadmap.md`）。
- 验证期内可以修 bug、加观测。指纹机制会记录这类代码变更，但不重置验证期。

## Considered Options

- 价格或资金费率异动时额外触发一次 LLM 研判：要改上游才能用盘中时点的数据，成本不可控，验证期后再评估。
- 现在就子类化 `TradingAgentsGraph`，往标的上下文里追加资金费率等数据：不碰上游文件，但验证期内换了输入，前后结果不可比。
- 分钟级响应新闻和价格的系统：是另一套设计，日频版本证明有效之前不做。
