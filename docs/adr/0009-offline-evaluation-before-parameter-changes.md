# 改策略参数先过离线评估：用真引擎回放已记录的信号

到 2026-11-10 为止，三个账户的策略常数（每单位风险、止损倍数、ATR 周期、调仓阈值、评级权重）都是拍的，唯一的检验是线上验证期——一次只能试一组，换一组就要重开验证期（ADR 0004、0006）。用户要求“尽可能把策略做到最好”，并选了“先建评估，再按数据改”。

所以加一层离线评估（`trader/evaluation/`，Issue #27），它不是另一套回测引擎，而是把线上的引擎接到历史数据上：

- **行情缓存** `HistoryStore`（`TRADER_HOME/evaluation/history.sqlite`）：OKX 公开接口的 K 线、资金费结算、合约规格，记住已抓取的区间，只补缺段；没收盘的 K 线不计入已覆盖。
- **历史市场** `HistoricalOKX`：和 `OKX` 同形的 `bars / last_price / funding / contract_spec`，但带一个时钟：只给那一刻前收盘的 K 线、最后一根已收盘 1 分钟 K 线的收盘价、已结算的资金费。引擎看不到未来。
- **参数注入**：`IntradayPaper` 的常数收进 `trader.intraday.settings.Params`，默认值就是原常数，生产路径用默认值；评估给同一个引擎别的值。没有第二份仓位逻辑可以和线上走样。
- **回放** `replay()`：从账本（或 JSON）取一段已记录的信号，逐小时调 `IntradayPaper.replay` 和 `execute`，决策放在那小时最后一条信号记录的下一分钟（没信号的小时按 `DECISION_MINUTE`），记到一个临时账本里；输出每小时净值、成交、午夜快照和指标（复用 `trader/report.py`）。参数可以网格。
- **策略层** `Policy`：在信号进引擎之前叠加的可选规则——信心分级仓位、换向需要最低信心、止损后冷却——默认全关，关着就是线上行为。这些规则只存在于评估层，线上要用要另写 ADR。
- **信号质量** `signals.py`：每条信号之后 1 / 4 / 24 小时的方向收益，按币、信心、方向归纳，换向频率。这是在仓位和止损之外单看信号本身有没有信息。
- **重跑**（第二期，Issue #28）`rerun.py`：线上的 `Signaler`（同一提示词、同一模型）对着 `HistoricalOKX` 逐小时在决策分钟问“当时会说什么”，引擎同步交易，所以提示词里的“当前仓位”就是规则当时会持有的仓位。每条回答存进一个账本文件（`TRADER_HOME/evaluation/rerun-<模型>-<提示词>.sqlite`，meta 记指纹，换模型或提示词必须换文件），按小时和币查缓存：断点续跑、不重复付费；`--budget` 花到即停；没花钱的失败（模型过载、拉不到数据）按 15/30/60/120 秒退避重试，连续三个空小时自动停。缓存文件可直接作为 `replay`/`signals` 的 `--ledger`。
- 命令行 `python -m trader evaluate fetch | replay | rerun | signals`，报告写 Markdown 到 `docs/reports/`。

验收标准是“回放要能复现线上”：用默认参数回放线上账本自己的信号序列，成交要逐笔对上，净值差要在几个基点内（2026-11-10 的首次对照：16 笔成交一一对应，午夜净值差 1.5 bp，见 `docs/reports/evaluation-intraday-2026-11-10.md`）。做不到这一点，网格里的任何差异都不可信。

## 规则

1. 线上三个账户的策略常数、模型、提示词不因评估结果自动改变。要改，先有跨越至少两三周、包含上涨和下跌段的回放证据，再由用户决定；改了就是新的验证期（ADR 0004）。
2. 评估只用已记录的信号或用同一提示词、同一模型在历史输入上重跑出来的信号（第二期）；不用事后才知道的信息。
3. 网格里“更好”的参数首先是对样本的拟合。报告必须写明样本长度、成交笔数和行情方向，结论不超出样本能支持的范围。

## Consequences

- `IntradayPaper(ledger, okx, watchlist, params=DEFAULT_PARAMS)` 多了一个参数；现有调用和测试不变，验证止损倍数的测试改为传 `Params(stop_mult=3.0)`。日频的 `Paper` 还没有收进 Params，第三期做。
- 行情缓存是本机文件，不进版本库、不备份；丢了重拉。三个币 30 天的 1 分钟 K 线约 13 万根，拉一个币一天的 1 分钟 K 线约 5 秒。
- 回放用决策前一分钟的收盘价代替线上那一秒的最新价，成交价差在几个基点；止损的触发分钟可能差一两分钟。这是已知误差，比较参数时两边一样。
- 评估的临时账本关掉了 fsync（`PRAGMA synchronous=OFF`），线上账本不受影响。
- 重跑的提示词输入和线上有四处已知差别，报告必须写明：① 日频研究只有 11-06 之后才有，更早的小时提示词里是“暂无日频研究”，模型会明确因此偏向观望，所以重跑序列衡量的是“没有日频研究时的小时信号”，不能拿来评价线上信号的胜率，只用来给规则层（止损倍数、ATR 周期、风险预算、再平衡阈值）更长的样本；② “当前资金费率”用那一期最终结算的费率代替当时的实时预估（两者只差几个基点内的收敛误差），下一期预测记为 n/a；③ 持仓量取 OKX 小时持仓量历史里决策前最近的一点（线上是实时值）；④ 行情读的是历史库里那一刻前收盘的 K 线，和线上一样不看未来。重跑不能补做历史的日频研究：研究流程会抓取当前新闻和数据，做不到“回到当时”，强行补做会带进未来信息。
- 历史库的连接可被重跑的几个工作线程共用，语句加了锁；线上代码不用历史库。
