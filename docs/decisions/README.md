# Decisioni architetturali (ADR)

Conservare qui le decisioni tecniche significative, una per file, con nomi come `0001-risk-engine-deterministico.md`.

Ogni ADR deve contenere:

1. **Contesto**: problema e vincoli.
2. **Decisione**: scelta adottata.
3. **Alternative**: opzioni considerate e motivi di esclusione.
4. **Conseguenze**: compatibilità, costi, sicurezza, test e migrazioni.
5. **Stato**: Proposta, Accettata, Sostituita o Revocata.

Non dichiarare *Accettata* una decisione non ancora verificata o approvata.
